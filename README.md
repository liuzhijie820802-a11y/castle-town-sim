# 3D仿真：城堡+城镇

基于种子（seed）的程序化生成：地形 + 城堡 + 城镇 + 角色。

## 在线预览

启用 GitHub Pages 后，打开仓库的 Pages 网址即可查看最新版本。
网址后可加参数复现全部设置，例如 `#seed=12345&relief=1.2&river=1&town=m&walls=2&mode=3d`。

## 操作

- 2D 俯视：鼠标悬停查看坐标和高度；按住城堡可直接拖动（手动覆盖自动选址）
- 3D 视角：左键拖动旋转，右键或 Shift+拖动平移，滚轮缩放
- 参数面板：地形起伏、河流有无、城镇规模（小/中/大）、城墙层数（1~3）
- 手动位置在改参数、换种子后都会保留，点「恢复自动选址」可撤销

## 验证环境

`tests/test_preview.py` 用无头浏览器做端到端检查，目前 24 项（加载无报错、同种子可复现、河流开关、自动选址不压河道（20 个种子批量）、参数生效、网址复现、拖动城堡与恢复自动等），并输出截图。

```
python3 tests/test_preview.py              # 测试本地 index.html
python3 tests/test_preview.py <线上网址>    # 测试已发布的页面
```
