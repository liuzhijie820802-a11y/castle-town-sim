# 规划层：分区与多中心（阶段 D 计划）

> 供 AI 读取的规划文档。人看的版本是设计好的预览页，内容一致。
> 状态：待用户确认方向（2026-10-11 起草）。

## 结论
下一阶段在"地形"和"3D 内容"之间加一层**规划图**：
地形（含河流，永不改动） → 规划图（中心、分区、主干道、人工覆盖） → 3D 内容（道路细节、地块、房屋、人物）。
规划图是可保存、可编辑的数据；3D 只按它补全。用户改规划图，AI 负责把改动落实到 3D 并验证。

## 1. 规划图的数据（plan.json）
```
{
  "version": 1,
  "seed": 3, "size": 512,
  "centers": [ {"id":"c1","type":"集市","x":228,"z":269,"weight":1.0,"locked":false} ],
  "zones":   {"cell": 8, "labels": "按格存分区编号", "painted": "用户刷过的格子，锁定"},
  "arterials": [ {"from":"城门","to":"c1","pts":[[x,z],...],"locked":false} ],
  "overrides": {"castle": {"x":174,"z":246}}
}
```
- 同一种子、同一份 plan.json 必须重现完全相同的场景。
- 保存方式：导出/导入文件 + 浏览器本地保存；URL 只存种子和参数。

## 2. 分区类型（初版 6 类，待用户确认）
| 分区 | 中心怎么放（软偏好，可调权重） | 对房屋和道路的影响 |
|---|---|---|
| 城堡 | 沿用现有：自动选址或用户拖动 | 城墙内不放民居 |
| 集市 | 城门外 30~80 米、主路交汇、坡度 ≤5% 的平地 | 房屋最密、临街、小地块 |
| 码头/河岸 | 离集市最近、岸坡平缓的可达河岸；无河则不生成 | 沿岸排布、长条地块 |
| 作坊 | 河流下游、靠水，离城堡和集市 ≥100 米 | 大屋、稀疏、院子 |
| 居住 | 1~3 个，按可建面积和到集市的步行距离自动放 | 中等密度，后排允许 |
| 农田 | 建成区外圈、平缓、靠水 | 不放房屋，只有田块和田间小路 |

分区划分：每个 8 米格按"到各中心的加权距离 + 地形适宜度"归属；河流、陡坡（>25%）作为天然边界；用户刷过的格子锁定不变。
道路：主干道先把城门、集市、码头、各居住中心连起来，再由现有生长方式在各区内长支路。

## 3. 检测项（口径由 AI 推演，阈值可再调；硬规则 H1~H9 不变）
| 检测 | 口径与目标 |
|---|---|
| 分区完整 | 可建地 100% 有分区；分区不跨河（桥头 20 米内除外） |
| 中心合理 | 集市坡度 ≤5%；码头离河 ≤15 米；作坊在下游且离城堡 ≥100 米 |
| 可达 | 每个中心与城门路网连通；居住区房屋到最近集市路程 ≤400 米（约步行 5 分钟） |
| 编辑保真 | 人工改过的中心、分区、锁定道路，重新生成后 100% 保留 |
| 局部性 | 移动一个中心后，离它 150 米以外的房屋保持不变的比例 ≥90% |
| 回归 | 现有 47 项验证全过，Q1~Q5、孤立房屋、地基平整、房屋数不退步 |
| 成本 | 512 米：一次编辑后的重生成 ≤0.3 秒（现在整城约 0.4 秒） |

## 4. 阶段计划（每步先出预览，用户看过再进下一步）
| 步骤 | 内容 | 用户看到的预览 |
|---|---|---|
| D0 规划数据层 | 把现有生成结果整理成 plan.json，可导出/导入；外观不变，同种子完全重现 | 2D 视图多一个"规划图"图层开关 |
| D1 多中心 | 自动放集市/码头/作坊/居住中心；道路改为从多中心出发 | 单中心 vs 多中心 A/B 对比 + 样本墙 |
| D2 分区 | 分区色块；房屋密度、尺寸、朝向按区取参数 | 分区色块图层 + 各区房屋对比 |
| D3 可编辑 | 在 2D 规划图上拖中心、刷分区、锁定道路，3D 跟着变 | 可直接操作的预览页 |
| D4 局部重生成 | 分块缓存，只重算改动附近；为 1024 米以上做准备 | 拖动流畅度对比 |
之后（阶段 E）：地块与建筑语法、建筑细节。

自动迭代循环：D0 由人工确认后，D1 起恢复循环，以上检测项作为闸门，每轮只修一个问题。
