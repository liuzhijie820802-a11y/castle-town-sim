# 验收指标 · 假成功率（FSR）

> 本文件给 AI 读，人看可视化版本：acceptance.html。两者内容保持一致，改一处同步另一处。

## 1. 两层标准

- **看起来对**：由用户看预览页判断（方向、观感、构图）。
- **真的对**：由验证脚本在真浏览器里自动检查，只用运行时能观察到的结果（页面状态、像素、几何数值），不依赖测试框架才有的信息。
- 尺度基准：角色身高 1.75 米。

## 2. 假成功率（FSR）

- 假成功 = 验证脚本判“通过”，但用户评审判“不对”。
- FSR = 假成功次数 ÷ 脚本判通过、且用户已给出结论的评审次数（待验收的不计入分母）。
- 每出现一次假成功：把用户指出的问题补成新的自动检查，再交付。
- 目标：阶段6 时 FSR ≤ 10%（20 个种子批量评审）。

## 3. 过程标准

- **收敛轮次**：一张卡从首次交付到用户验收通过的反馈轮数，应逐步下降。
- **停在不可逆之前**：会覆盖用户手动修改的操作先提示再执行；验证脚本未全部通过的版本不推送到线上。

### 阶段0 · 基础与验证环境
看起来对：打开即见地形，2D/3D 一键切换；改参数画面立刻变化；手动拖过的城堡不被冲掉。
- [x] 页面加载、全程无报错
- [x] 同一种子结果一致，不同种子结果不同
- [x] 网址能复现全部参数
- [x] 手动覆盖在改参数后保留，并可恢复自动
- [x] 3D 视角能看到城堡范围（开关叠加层像素差 > 500）
- [x] 一条命令跑完，输出清单和截图

### 阶段1 · 地形
看起来对：3 个种子 3 种不同但合理的地形；山丘、平原、河流可辨；编辑时上面的东西跟着贴合。
- [x] 高度在 0 ~ 32 米之间
- [x] 河流开关有效，河道贯穿地块
- [ ] 相邻网格高差 ≤ 3 米（无尖刺）
- [ ] 可建造区坡度 ≤ 15°
- [ ] 编辑地形后建筑底面与地面高差 < 0.1 米

### 阶段2 · 城堡
看起来对：城墙顺山势闭合，塔楼自然；城门朝向主路；内部建筑有机生长。
- [x] 城堡不压河道（20 个种子）
- [ ] 城墙闭合，无断口
- [ ] 墙基离地悬空 < 0.2 米
- [ ] 门高 ≥ 2.2 米，城墙走道宽 ≥ 1.5 米
- [ ] 楼梯踏步高 15 ~ 20 厘米
- [ ] 建筑之间不穿模

### 阶段3 · 城镇
看起来对：道路从城门自然长出；房屋朝向道路，越近城堡越密；街上能看到城堡。
- [ ] 所有道路连通到城门
- [ ] 道路坡度 ≤ 12%
- [ ] 房屋不压路、不重叠
- [ ] 过河处都有桥
- [ ] ≥ 60% 的街道采样点能看到城堡

### 阶段4 · 角色与磁吸放置
看起来对：守卫在城墙、商贩在集市、村民在街道和田里；拖动吸附自然。
- [ ] 任意放置，脚底与表面高差 < 5 厘米
- [ ] 角色只站在可行走面上
- [ ] 角色间距 ≥ 0.5 米，不重叠
- [ ] 角色身份与所在区域匹配

### 阶段5 · 材质 · 光照 · 渲染
看起来对：材质风格统一；清晨/正午/黄昏氛围对；每个机位有焦点。
- [ ] 阴影方向与太阳方向夹角 < 5°
- [ ] 3 ~ 5 个机位都能完整框住城堡
- [ ] 没有缺失或加载失败的材质

### 阶段6 · 整合与验收
看起来对：一键生成的完整场景，用户认为可以。
- [ ] 20 个种子全流程无报错
- [ ] 全部自动检查通过
- [ ] FSR ≤ 10%
